# APU GO: aprendizaje gamificado del quechua

## Integrante
Juan Josue Huamán Soto

## Descripción
APU GO es una propuesta de aplicación multiplataforma para apoyar el aprendizaje del idioma quechua mediante lecciones, actividades y elementos de gamificación.

## Caso de estudio
Análisis del sistema y diseño inicial de la arquitectura de APU GO, desarrollado a partir del proyecto final del curso.

## Curso
Arquitectura de Software (IS-488) — Semestre 2026-II

## Organización del repositorio
- `analisis-de-sistema/`: actores, historias de usuario, requisitos, atributos de calidad, restricciones y drivers arquitectónicos.
- `arquitectura/`: propuesta y diagrama de arquitectura inicial.
